How it works.
  • New tool create_document(title, content, format): Donna writes the content in Markdown (headings, lists, tables, bold), and the tool turns it into a PDF or keeps it as .md. Same pattern as pictures: the file lives in data/files, the chat only gets its name.
  • The card replaces the old "just pasted the text" answer. Clicking the card (not the button) opens a PDF in a new tab.
  • PDFs use a bundled open font (Noto Sans), so Hindi/Marathi text and ₹ come out right, also on the Linux server.
  • While it's being made: a thin moving bar. PDFs take under a second, so no percentage like the pictures.

What changes.
  • schedule_task gets a deliver_to argument (my WhatsApp, web only, or a contact), so "send it to me on WhatsApp" works when you set it up by chatting, from the web or from your phone. The Tasks page shows it as "Result goes to".
  • New tools the task can use: get_news(topics) (Google News RSS, free, no key) and upload_to_drive(file).
  • Drive needs one more Google sign-in, with access only to files Donna creates (drive.file), not your whole Drive.
  • A file made during a scheduled run is sent to WhatsApp as a document, the same way pictures are sent now.

Rules, enforced in code (not by the model).
  • Both Jira permissions are off for every contact until you switch them on.
  • "Comment on Jira" can never be plain On: each comment waits for your approval, like booking a meeting.
  • Contacts only see issues in the projects ticked in the Jira wizard; asking about OPS-12 gets "I can't share that".
  • Comments are posted from your Jira account, with a footer: "(added by Donna for Jyotiraditya)", so the history is honest.
  • You (web or your own WhatsApp) can also search, comment and move issues; moving one asks you first like other changes.
